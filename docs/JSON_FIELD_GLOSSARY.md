# =============================================================================
# TABELA Weekly Intelligence JSON Field Glossary
# =============================================================================

## Purpose

Authoritative reference for the Weekly Intelligence JSON schema.

This glossary defines the meaning of commonly used fields generated by TABELA.
It is intended for AI consumers, dashboards, future reporting engines and developers.

---

# General Fields

| Field | Definition |
|--------|------------|
| date | Trading date (YYYY-MM-DD) |
| generated_at | Timestamp when the Weekly Intelligence dataset was generated |
| start_date | First trading day included in the weekly dataset |
| end_date | Last trading day included in the weekly dataset |
| trading_days | Number of trading sessions included in the weekly review |

---

# Theme Fields

| Field | Definition |
|--------|------------|
| theme | Standardized investment theme |
| classification | Theme lifecycle classification for that trading day |
| rank | Daily theme ranking |
| score | Daily composite theme strength score |
| daily | Complete daily history for the theme during the review period |
| transitions | Theme lifecycle transitions observed during the week |
| start_rank | Theme rank on the first trading day |
| end_rank | Theme rank on the last trading day |
| best_rank | Highest (best) rank achieved during the week |
| worst_rank | Lowest rank achieved during the week |
| average_rank | Average rank across the review period |
| start_score | Theme score on the first trading day |
| end_score | Theme score on the last trading day |
| best_score | Highest theme score during the week |
| worst_score | Lowest theme score during the week |
| average_score | Average theme score during the review period |
| days_seen | Number of trading days the theme appeared |
| days_leading | Number of days classified as Leading |
| days_neutral | Number of days classified as Neutral |
| days_lagging | Number of days classified as Lagging |

---

# Theme Transition Fields

| Field | Definition |
|--------|------------|
| transitions | List of lifecycle changes during the week |
| from | Previous lifecycle classification |
| to | New lifecycle classification |

Example:

```json
{
    "date": "2026-07-16",
    "from": "neutral",
    "to": "leading"
}
```

# Maintenance Fields

## taxonomy_review

Objective evidence package used by the Weekly AI for taxonomy validation.

No recommendations are generated by the engine.

| Field | Definition |
|--------|------------|
| status | Current taxonomy review status |
| last_reviewed | Date of the Weekly Intelligence dataset |
| unknown | Unknown classification intelligence |
| stock_transition_registry | Historical persistence registry used during taxonomy review |
| theme_transitions | Weekly lifecycle transitions for every theme |
| theme_history | Complete weekly history for every theme |

# Design Principles

The Weekly Intelligence JSON stores **objective facts only**.

The engine does **not**:

- Recommend taxonomy changes.
- Explain market narratives.
- Infer institutional intent.
- Generate trading signals.

The AI consumes this dataset to generate higher-order institutional intelligence and taxonomy recommendations.
