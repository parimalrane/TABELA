# Recommended Improvements to TABELA

1. Add **Leadership Quality** metrics that distinguish strengthening leaders from weakening leaders.

2. Introduce **Acceleration (first derivative)** and **Deceleration (second derivative)** metrics for theme scores.

3. Create hierarchical taxonomy support (e.g., *Digital Infrastructure* above AI, Cloud, Telecom, Software, Internet, and Semiconductors).

4. Add **Relative vs Absolute Strength** flags to identify themes rising because they are improving versus those rising because competitors are deteriorating.

5. Replace threshold-only classifications with **trajectory-aware classifications** so rapidly deteriorating themes (such as Aerospace & Defense this week) are not masked by a neutral label.

6. Extend the Unknown audit with **mapping confidence**, **forced mapping rate**, and **taxonomy entropy**, preventing a zero-Unknown result from being interpreted as evidence that the taxonomy is complete.
